# 備品貸出管理アプリ

`agents.md` と `docs.md` に基づく備品貸出・予約管理アプリです。外部ライブラリやビルドは不要です。

## 起動

`index.html` をブラウザで直接開いて使用します。サーバーの起動は不要です。データを継続して使う場合は、同じブラウザ・同じファイルの場所で開いてください。`file://` での LocalStorage の扱いはブラウザによって異なるため、使用するブラウザで予約ページとのデータ共有と再読み込み後の保存を確認してください。

一覧ページ (`index.html`) の「備品名の登録」で備品を登録します。「予約・貸出を登録する」から予約ページ (`reservation.html`) に移動し、登録済みの備品・借りる人・利用開始日・返却予定日を指定します。予約・編集の保存に成功すると一覧ページへ戻り、失敗した場合は入力を残してエラーを表示します。

一覧は「予約中」「貸出中」「返却済」の3つのタブで切り替えます。各タブに件数を表示し、予約は開始日の近い順、貸出は期限超過を先頭に返却予定日の近い順、返却済みは返却日時の新しい順に並べます。貸出・返却操作後は移動先のタブを表示します。選択したタブは、HTMLファイルを直接開く場合はブラウザの保存領域に、それ以外ではURLの末尾に保持され、再読み込みでも維持されます。取消済みの予約はタブとは別の「取消した予約の履歴」に残します。

日付は直接入力とカレンダーで指定でき、過去日は申請できません。返却予定日は開始日と同じ日が初期値で、後日に変更できます。名前の入力は前後の空白を除き、各100文字までです。

予約は利用開始日から返却予定日まで「貸出する」で貸出を開始できます。予約中の行に「編集」「予約取消」を表示します。編集できるのは予約中の記録だけです。変更時も備品の存在、過去日、期間の逆転、他の予約・貸出との重複を検証します。取消済み・返却済みの履歴を残します。

備品の管理IDで同じ1台を識別し、開始日・返却予定日を含む重複した期間の貸出・予約を拒否します。同じ名前の備品は重複登録できません。複数台ある備品には「PC-01」「PC-02」のような名前を付けてください。前の利用者が未返却の場合も二重貸出を防ぎます。

「返却」を押した日時を保存し、一覧に秒まで表示します。返却予定日の翌朝10時ちょうどまでは警告を出さず、その直後から未返却の貸出を赤く強調して先頭に表示します。猶予中でも未返却なら次の人に貸し出せません。画面への復帰時と1分ごとに期限表示を更新します。

旧データは元の貸出日を開始日・返却予定日として補完し、以前の記録に登場する備品名も選択肢に引き継ぎます。日付・時刻はブラウザのローカル時刻で判定します。

## 保存と構成

データは使用中のブラウザの LocalStorage に保存します。端末間での共有はありません。ブラウザの保存データを削除すると記録も消えます。破損データを検出した場合はエラーを表示し、元データを保護するため登録を停止します。

- `js/app.js`: 一覧ページの起動・備品登録・返却・予約取消
- `js/reservation.js`: 予約ページの起動・新規登録・編集・保存後のページ移動
- `js/models/`: データ生成・旧形式の補完・保存形式の検証・重複と期限のルール
- `js/repositories/`: 備品マスタ・登録・編集・貸出開始・返却・予約取消（公開メソッドは Promise ベース）
- `js/services/`: LocalStorage の読み書き
- `js/ui/`: 一覧・メッセージ・フォーム・カレンダーの表示
- `js/utils/`: 入力チェック

保存先を変更する場合は repository と storage を置き換えます。ユーザー入力の表示には `textContent` を使用します。

## 自動テスト

```sh
TZ=Asia/Tokyo node --test tests/repository.test.cjs tests/reservations.test.cjs tests/equipment.test.cjs
```

Chrome がインストールされている環境では、ブラウザでの操作も検証できます（Node.js 22 以降）。Chrome の場所が異なる場合は `CHROME_PATH` で指定してください。

```sh
node --test tests/browser.test.cjs
```

HTMLファイルを直接開く運用は、サーバーを起動せず次のコマンドで検証できます。

```sh
BROWSER_FILE_MODE=1 node --test tests/browser.test.cjs
```

備品登録・選択、予約・編集・取消・貸出・返却、ページ遷移、カレンダー、過去日の拒否、翌朝10時の境界、返却日時、旧データの互換性、再読み込み、二重送信、HTML文字列の安全な表示、100件の一覧、保存失敗、データ破損を検証します。PC幅で確認する場合は `BROWSER_WIDTH=1280` を指定します。

タブの状態別表示・件数・空状態・返却日時の並び・再読み込み・キーボード操作・貸出と返却後の切り替えも検証します。

## 検索・一括操作・統計

- 一覧上部の検索欄で備品名・利用者名を絞り込めます。空白で区切るとAND検索になります。英字の大小や全角・半角は区別しません。状態タブの件数も検索条件に合わせて更新します。「貸出中」タブと登録済み備品のカードで、現在の利用者を確認できます。
- 「備品を一括登録する」を開き、備品名を1行に1件貼り付けます。空行は無視します。既存名・入力内の重複や100文字超過があれば全件を保存せず、入力を保持します。
- 予約画面では名前を検索し、選択欄から備品を追加できます。選んだ備品は検索語を変更しても保持します。備品名の「×」で選択を解除します。同じ利用者・期間でまとめて予約、または「今から借りる」でまとめて貸出登録できます。既存予約の編集は1件ずつです。
- 予約中一覧のチェックボックスで貸出可能な予約を選び、「選択した予約をまとめて貸出」を押します。すべて選択は表示中の貸出可能な予約が対象です。検索語や状態タブを変えると選択を解除します。1件でも貸出不可なら全件を変更しません。
- 「統計CSVを出力」で全期間・全登録備品の統計をダウンロードします。検索条件には依存しません。列は備品名、予約中・貸出中・返却済・予約取消・期限超過の件数、累計貸出回数です。累計貸出回数は貸出開始済み（貸出中＋返却済）の記録数です。未利用の備品は0件で出力します。Excel向けのUTF-8 BOM付きで、カンマ・引用符・改行をエスケープし、数式として解釈される名前を保護します。
- ヘッダーに現在の画面を示すナビゲーションを配置しました。予約画面には手順と一覧へ戻るボタンを表示し、保存後は対応する状態の一覧へ移動します。

